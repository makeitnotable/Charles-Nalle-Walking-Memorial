# Client round 6 — Charles Nalle Walking Memorial (v2)

One fix Wil asked for after round 5: the chapter footer's Share button
(clipboard fallback when `navigator.share` is absent) never showed its
"Link copied" state. Base `016710c` = the `v2` tip, tagged locally
`client-round-6-base`.

## The bug
`src/pages/[chapter].astro`'s handler wrote the copied label into the
button's LAST child node. `Button.astro` renders the label text followed by
the trailing `<svg>` icon (`icon-end`), so the last node is the SVG: the text
landed inside it (unrendered) and wiped the icon's paths.

## The fix
Write to the button's first non-empty text node instead. Nothing else in the
handler changes (native share sheet first; the copied state stays until the
page is left, as authored).

## Verified
Headless Chromium on the built site, `navigator.share` removed, clipboard
granted: after the click the button reads "Link copied" (rendered in caps by
`.btn-sm`), the icon keeps its three paths, nothing sits inside the SVG. No
route drifts at rest (Share is below the fold).

## Revert
`git reset --hard client-round-6-base` (= `016710c`).
