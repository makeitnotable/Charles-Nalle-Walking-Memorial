# Footer research — award-winning memorial / museum / archive / foundation / editorial sites

Method (2026-08-15): candidates pulled from Awwwards tag listings (`/websites/memorial/`, `/museum/`, `/foundation/`, `/history/`, `/institutions/`), award status confirmed on each Awwwards site page, then the live footer markup + CSS was downloaded with curl and read directly (class names / Tailwind utilities quoted below are from the live source). Where a site could not be fetched or has no footer, that is noted.

## (b) Footer references — 10 lines

1. Two-tier structure is the norm on the best cultural footers (LAS, Pentagram, MAM, Obama OH): a content grid, then ONE full-width hairline, then a small muted meta row — so a `rule-top` disclaimer row under the 3-col grid is exactly the reference pattern; keep the disclaimer alone (or with "Made by Notable" right-aligned via `justify-content: space-between`) at 0.75–0.875rem, muted (~60–65 % of body colour), single line on desktop, wrapping freely on mobile.
2. 3-col desktop grid: wordmark block left, nav as a plain vertical `<ul>` centre, Share/action right — matches LAS (logo · list · list) and Draw History (logo+nav · statement · credit); give the wordmark column the widest span (LAS: 3 of 12 cols for the mark, nav lists 2–3 cols each starting at col 6) so the right column can be narrow and calm.
3. Mobile stacking order seen everywhere: wordmark → nav → action/social → hairline → legal; Augustinus flips it (nav first, org block last) via `order`, which is worth copying only if the nav is the primary reason to reach the footer — for CNWM keep wordmark → nav → Share → rule → disclaimer, with `gap ≈ 1.5rem` between blocks (LAS `gap-y-6`) and columns separated by horizontal hairlines when stacked (Draw History `divide-y`).
4. Large quiet decorative wordmark IS common on memorial/museum footers (MAM stacked 3–8rem wordmark, Käthe Kollwitz giant subject-name h1); it is kept quiet by (a) same colour as body type at reduced opacity or a hairline-ruled setting rather than a fill colour, (b) tight `line-height .75–.9` and negative tracking, (c) a `clamp(3rem, …, 8rem)` size cap, and (d) lots of air — MAM pads 6–6.5rem below it. For CNWM's Libre Caslon: one line, `clamp(1.75rem, 4vw, 3rem)`, normal case, colour = text at ~70 %, no rule needed.
5. Nav treatment: plain vertical list, no column heading, `0.875–1rem` type, `~0.35–0.5rem` vertical rhythm per item (LAS `gap-y-1`, Augustinus `py-1.5`), hover = underline with offset (MAM `text-underline-offset .35em`) or the arrow-reveal/`translate-x` slide (Augustinus, Draw History) — the arrow-reveal is the closest match to the site's existing "arrow" link idiom; do not add icons or headings.
6. Hairlines: always 1px (Tailwind `h-px`/`border-t`; MAM uses 1.25px), same hue as text at low alpha (Draw History `warm-sand` @ 40 %, LAS `border-strong` token) — never pure grey on a warm dark ground; use one full-width rule above the disclaimer row and, optionally, one full-width rule at the very top of the footer (ROM, Pentagram `keyline-t`); avoid rules between the three columns on desktop unless the columns are equal-width panels (Draw History).
7. Vertical padding conventions: footer top padding 2.5rem (LAS/ROM `pt-10`) to 3.75rem (ROM lg `py-15`) on the top edge; grid → hairline gap 2rem (LAS `mt-8`), hairline → legal row 1.75rem (LAS `pt-7`) or ~1.125rem (MAM); bottom padding 2.5–2.75rem (LAS `pb-10/11`) up to 6rem when a giant wordmark sits above (MAM). Recommended for CNWM: `padding: 3rem 0 2.5rem`, `.rule-top { margin-top: 2rem; padding-top: 1.5rem; }`.
8. Credit / colophon ("Made by …", "Website by …", "Fonts by …") is a first-class element on 5 of 8 references and always sits at the smallest size, muted (Draw History 50 % opacity, LAS `text-text-secondary`), on the meta row or in the wordmark block directly under the name; "Made by Notable" belongs under the wordmark at ~0.8125rem, muted, with the disclaimer alone on the rule-top row.
9. Share/action column: references use a single low-key text link or a bordered pill (Augustinus `border border-midnight px-5 py-[0.6875rem]` with a sliding arrow); a text link "Share →" using the site's arrow idiom, top-aligned with the nav's first item, is the most consistent choice — no social icon row (LAS/ROM icon rows read as institutional, not memorial).
10. Tone: the strongest memorial footers (Kollwitz, Draw History) let one element carry weight — the name — and set everything else in the same small size; the strongest institutional ones (LAS, Pentagram) win on rhythm — every row = keyline + fixed padding. CNWM should combine both: quiet large Caslon wordmark, everything else 0.875rem, one hairline, fixed rem padding, no extra decoration.
